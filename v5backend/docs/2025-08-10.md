## Agentic Processing Pipeline
**Enterprise-grade extraction with multi-stage validation and fallback systems**

### Stage 1: Ingestion & Preprocessing (`process_resume_io`)
- **Queue**: `io` (high concurrency: 24 workers)
- **Process**: 
  1. Download from S3 staging bucket
  2. Content deduplication via SHA256 hashing
  3. Text extraction (PDF/DOCX) with OCR fallback (Tesseract)
  4. Section-aware chunking with overlap
  5. Schema migration (section column) enforcement
- **Output**: Resume text + sectioned chunks in database

### Stage 2: Embedding Generation (`embed_chunks_io`)  
- **Queue**: `io` (high concurrency: 24 workers)
- **Process**:
  1. Batch embedding generation via `bge-m3` (1024 dimensions)
  2. **Enhanced** - Adaptive storage (pgvector if available, text fallback otherwise)
  3. Async processing for optimal throughput
  4. **NEW** - Automatic vector format detection and conversion
- **Output**: Vector embeddings stored in `resume_chunks` table (format depends on pgvector availability)

### Stage 3: Agentic Fact Extraction (`analyze_resume_llm`)
- **Queue**: `llm` (controlled concurrency: 3 workers)
- **Process**:
  1. **Map Phase**: Parallel extraction over individual chunks
  2. **Merge Phase**: Intelligent fact consolidation and normalization
  3. **Validation Phase**: Schema validation against structured models
  4. **Summarization**: Multi-level summaries (short/detailed)
  5. **QA Consistency**: Cross-field validation and confidence scoring
  6. **Fallback Cascade**: Full-text re-extraction if confidence < 0.6
- **Models**: `qwen2.5:3b-instruct-q5_0` → `qwen2.5:7b-instruct-q4_K_M` (fallback)
- **Output**: Structured facts + confidence scores + QA validation
