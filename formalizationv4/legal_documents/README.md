# Legal Documents Directory

This directory contains legal documents for the HR Legal RAG system.

## Instructions for Use

1. **Add Your Legal Documents**: Place all your .txt files containing HR legal information in this directory.

2. **File Format**: 
   - Files must be in UTF-8 encoded .txt format
   - Any .txt files in this directory will be automatically processed

3. **Document Types Supported**:
   - Legal textbooks
   - Employment law codes
   - Case law documents
   - Regulations and policies
   - HR compliance guides
   - Government circulars

4. **Automatic Processing**:
   - Documents are processed during Railway deployment
   - The system automatically chunks, embeds, and indexes the content
   - No manual processing required

5. **Updates**:
   - To update the knowledge base, add new .txt files and redeploy
   - The system will detect and process new files automatically

## Current Status

## File Naming Recommendations

- Use descriptive filenames (e.g., "employment_act_2023.txt")
- Avoid special characters in filenames
- Keep filenames under 100 characters
