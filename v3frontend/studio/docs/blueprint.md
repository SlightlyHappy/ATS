# **App Name**: Bear Systems - HRT

## Core Features:

- Admin Dashboard: User-friendly dashboard presenting key metrics, resume statuses, and quick actions.
- Resume Management: Interface for admins to manage and filter resumes, view analysis results, and perform actions like re-running analysis or archiving.
- AI Insights Tool: Integrate AI analysis summaries from various agents, providing insights into technical skills, experience, cultural fit, and legal compliance. LLM reasons to incorporate insights in summary.
- Resume Display and Search: Display of uploaded resumes with file viewer and download link, raw text search, and overall AI scores.
- User Management: Management interface to list users, their roles, plan details, and enable actions such as inviting new users and role assignments.
- User Profile Management: User profile page with options to edit personal details, view subscription plans, and manage account settings.
- Resume Submission: Form allowing users to upload resumes with optional job descriptions to trigger AI processing.

## Style Guidelines:

- Primary color: Soft lavender (#D1C4E9) for a calm and professional atmosphere.
- Background color: Light grey (#F5F5F5), nearly white, for a clean and modern look.
- Accent color: Dusty rose (#C2185B) for important actions and highlights, creating visual interest.
- Body and headline font: 'Inter' (sans-serif) for a clean and modern reading experience across all devices.
- Use a set of simple, professional icons to visually represent actions and data.
- Maintain a consistent 8px grid layout with well-spaced elements for a clean and organized appearance.
